# 别和孔子抬杠—哲学思辨语音房，寻找你的哲学人格

走进一间坐满十二位哲学家的语音房：孔子、老子、庄子、苏格拉底、尼采、萨特……每一章先看一则《论语》小故事，再和哲学家们当场思辨。十章之后，根据你的发言找到你的本命哲学人格，并生成可分享的人格报告海报。

纯 HTML / CSS / JavaScript 静态前端，无需构建工具，浏览器直接可跑。内容依据 [`docs/12哲学人格.md`](docs/12哲学人格.md) 与 [`docs/论语十题 · 十二哲学人格测评系统（游戏正式版）.md`](docs/论语十题%20·%20十二哲学人格测评系统（游戏正式版）.md) 实现。

## 快速运行

推荐用本地服务器打开（视频、分享等功能依赖 http 环境）：

```bash
cd dont-argue-with-confucius   # 或你本地的项目文件夹
python3 -m http.server 8123
```

访问 <http://localhost:8123>。直接双击 `html/index.html` 也可以运行。

## 游戏主页面

- 顶部左侧返回首页按钮，点击弹出“是否重新开始？”确认框
- 顶部右侧章节目录，未解锁章节灰色不可点击；底部 10 个章节圆点显示状态
- 点击“开始游戏”后**直接进入 12 人语音房**，不再单独停留在故事页
- 每章先播放小故事视频；观看浮层盖在语音房上，房间座位保持可见
- 玩家看完视频与故事后，**直接自动进入思辨环节**，无需等待
- 思辨阶段为 12 人语音房：**左右各 6 位哲学家**（每侧 2 列 × 3 行），中间玩家头像
- 每章随机抽 6 位哲学家发言，发言时头像金圈高亮并弹出气泡；玩家有 2 次发言机会
- 完成一章解锁下一章；全部完成后进入人格报告

## 十二哲学人格

东方六道（心性·秩序阵营）：孔子、老子、墨子、韩非子、庄子、王阳明

西方六道（逻辑·自由阵营）：苏格拉底、柏拉图、亚里士多德、康德、尼采、萨特

每位人格包含：核心本源、人物定位、人格特质、专属天赋、人格弱点、角色语录、人物描述，完整文案来自 `docs/12哲学人格.md`。

## 十则《论语》测评故事

1. 己欲立而立人（利他与处世）
2. 颜回陋巷安贫乐道（物质与精神）
3. 以直报怨（善恶底线）
4. 阳货之避（本心与世俗仕途）
5. 陈蔡绝粮（理想逆境坚持）
6. 宰予昼寝（教化与人性管束）
7. 父为子隐（人情 VS 律法）
8. 孔子见南子（本心与舆论）
9. 三人行必有我师（学习与思辨）
10. 道不行，乘桴浮于海（理想破灭选择）

## 评分体系

按照正式版测评文档实现：

- 每题对 12 个哲学人格维度分别打 **0–10 分**
- 每题满分 10 分 / 维度，10 题满分 100 分 / 维度
- **12 维度中最高分 = 玩家本命哲学人格**
- 同分优先级：颠覆（尼采）> 本心（王阳明）> 思辨（苏格拉底）> 秩序（韩非子）

当前原型用关键词启发式把玩家发言换算成每题各维度的 0–10 分（关键词命中 + 每题的倾向权重），报告页展示 12 条“人格契合度”数据条。后续接入大模型评分时，只需替换 `js/report.js` 的 `computeScores`，数据结构和展示不用改。

## 分享海报

- 报告页左上角新增主页 icon，点击直接返回首页
- 点击“分享报告”会在弹窗中生成一张报告图片（Canvas 绘制，无需第三方库），包含玩家头像与昵称、本命人格名称与称号、人格语录、人格解析和测试网址
- 弹窗中点击“保存图片”即可下载 PNG；手机上也可以长按图片保存到相册
- 海报上的测试网址在 `js/assets.js` 顶部的 `SITE_URL` 常量中修改

## 原型阶段说明

- 微信 / 手机号登录均为模拟，接入真实登录后替换 `js/home.js` 中的 `mockLogin`
- 语音发言按钮为占位，接入语音识别后替换 `btnVoice` 逻辑
- 评分是关键词启发式，接入大模型后可替换 `js/report.js` 的 `computeScores`
- 进度保存在 localStorage，更换浏览器或清除缓存会重置
